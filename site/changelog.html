0.2.4 27 September 2026 current

Every core. DATUM now puts all of your processor to work, the window stays live while it does, and big imported models are many times faster to work with.

  • The window no longer freezes. A rebuild that will take a while happens in the background, and meanwhile you can still orbit, pan, zoom and drag dLogic sliders. A hole through a 300 solid Inventor export used to freeze the window for 21 seconds; now for a tenth of a second.
  • Sliders build ahead. While a dLogic form is open, the spare cores build the values your slider is heading for, so the model follows the drag instead of catching up after it. One step of the stair sample went from half a second to a fifteenth.
  • STEP files open as assemblies, the way Inventor does: every part and sub assembly as its own file, with its colour, its name and its instance names, each part stored once however often it is used. Or import one as a single part, as before.
  • Big imports stay quick. Only what changed is rebuilt and only what changed is redrawn. Commands that do not touch the solid, a sketch, a rename, a material, no longer rebuild it at all. A STEP file is read in the background the first time and from a cache after that.
  • Everything on every core: the parts of an assembly build side by side, drawing views are drawn side by side, and mass properties are worked out a piece at a time and only for the pieces that changed. An assembly of 26 parts builds four times faster, a drawing sheet three times, and the weight of a big import after an edit comes back in a quarter of a second instead of four and a half.
  • Editing a part in an assembly keeps your view. Stepping into a part no longer throws the camera somewhere else, and coming back out keeps any turn you gave it inside.
  • A new sketch faces you. Start one on a face and it is drawn from the side you were looking at, not swung round behind the part, and an extrusion from it comes out of the face. Sketches in existing files are untouched.
  • Section hatching is right on cut faces with notches and steps in them, which used to fill as wedges.
  • Closing a tab frees its memory, including for very large imports.
0.2.3 26 September 2026

dLogic grows up: code that builds geometry, rules that reach the whole model, forms with sliders, and an update that tells you when it could not finish.

  • Code features. A feature in the tree whose solid is built by a short Python script, rebuilt whenever a parameter moves. Boxes, cylinders, bars between two points, extrude, revolve, sweep along paths and helices, booleans, copies along a line or round an axis. Anything a loop can describe: stairs, railings, frames, bolt circles.
  • A staircase sample. examples/railing is a stair built entirely from two code features and two rules. Change the number of steps and every tread, stringer, baluster and the handrail are worked out again.
  • Forms with sliders. A rule can open a window whose sliders, number boxes and lists drive parameters, and the model moves while you drag. Cancel puts everything back. Pin a rule as a button and its form is one click away.
  • Rules reach the whole model. Sketch dimensions, features, components in an assembly (move, place, suppress, hide), properties such as the part number, material and appearance.
  • Rules choose when they run: after a rebuild, when the document opens, before it is saved, or when a named parameter changes.
  • An editor that shows you what is there. Everything a script can use is listed beside it, the model's own parameters and dimensions first, and a double-click puts it in. Names are offered as you type, the code is coloured, and the line that failed is lit up in red.
  • Trust you can manage. A file carrying code opens with the dLogic panel explaining why its code has not run. Allow it for this session, or always allow a folder you trust. Allowing an assembly allows the parts it places.
  • dLogic on every tab: assemblies, drawings and CAM sheets have the button too.
  • Updating from inside DATUM is fixed. The update helper now runs from the installation folder, keeps a log, and if an update cannot finish DATUM says so on the next start instead of quietly doing nothing. It is the new version that carries this, so if updating from 0.2.2 still does nothing, download the installer once and every update after that goes through the new helper.
  • File works on the home page, so Open and Check for Updates are there before any document is. New asks whether you want a part, an assembly, a drawing or a CAM sheet.
  • Assemblies open faster again. Every part was being built twice as it loaded. Now it is built once.
0.2.2 26 September 2026

Rules, editing a part inside the assembly it belongs to, and opening a large assembly nineteen times faster.

  • dLogic. Rules that drive a document, in parts, assemblies, drawings and CAM sheets alike. A rule reads the parameters, works something out and writes them back, and the model rebuilds around the answer. The language is Python, which is what DATUM itself is written in, so a rule is not a guest in the application and there is nothing it cannot reach. Rules run when you ask and after a rebuild if they say so.
    Nothing runs until you allow it. A document that carries rules can run code on whatever machine opens it, so a file arrives untrusted every time, and it is you who says otherwise, not the file.
  • Edit a part in place. Double-click a component and edit it where it sits, with the rest of the machine ghosted around it. No new tab: the assembly stays in the tree with the part you stepped into bolted inside it, and Return comes back up one level at a time however deep you went.
  • Two ways to read the tree. Assembly shows what holds a component in place, Modeling shows what it is made of. Same components in the same order either way.
  • Opening an assembly is about nineteen times faster. The excavator sample went from 5.3 seconds to 0.28. Part files store a feature tree and no geometry, which is the right thing to store, but it meant every assembly rebuilt every component from scratch on every open. Built bodies are now kept on disk, keyed on the exact bytes of the part they came from, so editing a part by a millimetre makes the old body unreachable rather than merely unlikely.
  • Booleans use more than one core, which is worth about 7 per cent on a full assembly build.
  • Relationship icons that mean something. Mate, Flush, Angle, Tangent and Insert each get their own glyph instead of borrowing the sketch constraint ones. They were borrowed, and somebody on r/AutodeskInventor read the result exactly as it was drawn.
0.2.1 26 September 2026

Materials and appearances, a long list of things that were wrong with sketching and assemblies, and somewhere to put your name.

  • Materials and appearances, kept apart. A material is what a part is made of and decides what it weighs; an appearance is what it looks like and changes not one gram. Both are libraries you can edit, with 18 materials and 30 appearances to start from, and anything you make is saved beside your settings where an update cannot take it away. Pick them from the top-left of the window. In an assembly the picker follows the selected component and writes the material into that part's own file, so every assembly using it agrees about what it is.
  • Sketching that behaves. Coincident now takes a point and a line, or a point and the middle of a line, not only two points. A dimension between a line and a point measures across to it, and between two lines gives a distance when they are parallel and an angle when they are not.
  • Project Geometry takes the edges you point at rather than the whole body, and projected edges now follow the model: change a dimension near the top of the tree and the sketches below it move with it instead of staying where the old shape used to be.
  • The SpaceMouse works inside a sketch, which it did not before.
  • Assemblies. Drag an unconstrained component with the mouse and no tool at all. Copy and paste. Open Part, suppress, ground and delete from the right-click menu. Save and Replace a component in one step. Box selection in both directions, blue for what is fully inside and green for anything the box touches, and Delete acts on whatever is picked without asking first.
  • Preferences. Your name, initials and company, stamped onto every new part, assembly and drawing, where the title block and the parts list already knew to ask. Document properties - title, part number, designer, revision - are editable in the Properties window. The viewport background and the sketch line colours are yours to change, and stay out of the files you send anybody.
  • An excavator to look at. A second worked example ships with the source: 26 parts and 48 components, with a linkage whose links are cut to fit the pose. The plywood tote stays, because it is the one that goes all the way to a DXF.
  • Smaller things. Ribbon panels are separated the way Inventor separates them. The Properties dock no longer takes a third of the tree. A part's sketches no longer follow it into an assembly view. Materials you made yourself are loaded at startup, which they were not.
0.2.0 23 September 2026

The first public release. Everything below is what DATUM can do as of this version.

  • Modelling. History-based solids on OpenCASCADE: extrude, revolve, sweep, loft, fillet, chamfer, shell, holes, rectangular and circular patterns, mirror and booleans. Features stay editable, and edges keep their fillets when dimensions upstream change.
  • Sketching. Lines, arcs, circles, splines, rectangles, fillet, trim and offset, with coincident, horizontal, vertical, parallel, perpendicular, tangent, equal, concentric, collinear, midpoint, point-on and symmetric constraints. Dimensions can be named and referenced by other dimensions, and accept expressions like (10-2+d2)/2.
  • Assemblies. Place parts by reference rather than by copy, constrain them mate or flush with an offset, and see which way a face points before you pick the second one. Editing a part in its own tab updates the assembly.
  • Drawings. Base, projected, section, detail and auxiliary views with hidden line removal. Sections hatch their cut faces from the model's material. Parts lists read the assembly and balloons take their numbers from the list. Dimensions snap to model vertices and follow the model when it changes. True vector PDF, SVG, DXF and print.
  • 2D CAM. Nest flat parts on a sheet, offset toolpaths for the cutter, add leads and dogbone corner relief, and export DXF.
  • Projects. An Inventor-style project file per folder, with its own recent files and its own drawing templates.
  • Updates. DATUM checks for new versions and fetches only the files that changed, so a typical update is a few megabytes rather than another full install. Releases are signed, and an update that does not verify is refused.
  • 3Dconnexion SpaceMouse support, over raw HID or the 3DxWare driver, whichever is available.
