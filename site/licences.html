Libraries DATUM includes

These are shipped inside the installer. Each is used unmodified, and each stays a separate file in the install folder rather than being compiled into DATUM, which is what lets you replace one if you want to.

Qt, through PySide6

The interface, the drawing painter, the PDF and SVG output and the printing all run on Qt. Used under the LGPL version 3.

The Qt DLLs sit in _internal\PySide6 in the install folder. You may replace them with your own build of the same version.

LGPL-3.0

OpenCASCADE, through cadquery-ocp

The geometry kernel. Every solid, boolean, fillet and hidden-line projection is OpenCASCADE doing the work. Used under the LGPL version 2.1 with the OCCT exception.

Its libraries sit in _internal\cadquery_ocp.libs and _internal\vtk.libs and may likewise be replaced.

OCCT licence

VTK

Not used by DATUM directly, but OpenCASCADE's Python binding links it, so it has to be present for the kernel to load at all. BSD 3-clause.

VTK licence

Python

The runtime DATUM is written in, under the PSF licence, together with NumPy (BSD) for the numerical work and the cryptography library (Apache 2.0 / BSD) for checking that an update really came from IITEG.

PSF licence
If you want the source of any of these libraries, each project publishes it at the links above, and the exact versions DATUM ships are listed in the install folder's _internal directory. If you would rather have it from me, write to datum@iiteg.com and I will send it.
